# Grading rules and assumptions

Source: *Student Examinations Handbook 2023-24*, Manipal University Jaipur  
https://jaipur.manipal.edu/img/pdf/exam/Student%20Examination%20Handbook%202023-24%20(11.08.2023).pdf

## Verified

Letter grades and grade points:

| Letter | Points |
| --- | --- |
| A+ | 10 |
| A | 9 |
| B | 8 |
| C | 7 |
| D | 6 |
| E | 5 |
| F / I / DT / S / U | 0 |

GPA / SGPA is credit-weighted:

`GPA = Σ(Ci × Gi) / Σ(Ci)`

CGPA is the credit-weighted combination of semester GPAs (handbook example: 8.48, 8.62, 8.24, 8.42 over 25+25+26+26 credits → **8.44**).

Typical evaluation weights from AY 2023-24 **except Faculty of Design**:

- Mid Term Exam (MTE): 30
- Class Work Sessionals (CWS): 30
- End Term Exam (ETE): 40

Relative grading is used when a course has **more than 25 students**; otherwise absolute grading. Letter grades use the cohort mean and standard deviation of **total** in-semester + end-semester marks.

Passing floors stated in the handbook: UG 35% in ETE and overall; PG 40% in ETE and overall. Attendance shortage yields **DT**.

## Not verified / not invented

- Official mark-to-letter cutoffs for a given course (relative grading is cohort-specific).
- Faculty of Design weights.
- Whether SLCM internal-marks tables already include official weightage columns.
- Programme-specific credits excluded from CGPA (some handbooks exclude open electives). The predictor uses whatever credits the user confirms or the grades table exposes.

The marks feature may apply handbook MTE/CWS/ETE weights **only when the page does not show weightage**, and labels that as an assumption.

Grade-letter prediction from internals is disabled unless the user supplies optional absolute boundaries in Settings. Those boundaries are exploration values, not official MUJ cutoffs.
